# MediaHub-AI-Node v0.8.23

## Änderungen

- Versionsnummer des MediaHub-AI-Node auf 0.8.23 aktualisiert.
- Der `/health`-Endpunkt liefert jetzt zusätzlich die installierte AI-Node-Version über das Feld `version`.
- MediaHub kann dadurch die tatsächliche Version des verbundenen Raspberry-Pi-AI-Node erkennen und anzeigen.

## Windows Compute Node

- Windows Compute Node bleibt unverändert auf Version 0.1.2.
- An der Windows-Compute-Node-Version wurden für diesen Release keine Änderungen vorgenommen.

## Getestet

- Python-Compile erfolgreich.
- Ruff-Prüfung erfolgreich.
- Vollständige Testsuite erfolgreich: 216 Tests bestanden, 2 übersprungen.
- Bestehende AI-Node-Funktionen bleiben unverändert.
