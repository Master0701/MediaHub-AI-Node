## Installation

### Empfohlen: Installation über das Release-ZIP

1. Unter **Assets** die Datei `MediaHub-AI-Node_v0.7.1.zip` herunterladen.
2. Optional die Datei `MediaHub-AI-Node_v0.7.1.zip.sha256` herunterladen und die Prüfsumme kontrollieren.
3. Das ZIP-Paket auf dem Raspberry Pi oder Linux-System entpacken.
4. Der Anleitung in `docs/INSTALLATION.md` folgen.

### Direkte Installation über Git

```bash
git clone https://github.com/Master0701/MediaHub-AI-Node.git
cd MediaHub-AI-Node
```

Danach der Anleitung in `docs/INSTALLATION.md` folgen.
